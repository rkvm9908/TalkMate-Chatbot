# TalkMate – Interactive Rule-Based Chatbot

TalkMate is a responsive, rule-based chatbot built using React.js and JavaScript.  
It provides real-time conversational interaction with intelligent message matching and utility-based chatbot functionalities.

## Features

- Intelligent fuzzy string matching for user input recognition
- Real-time asynchronous chatbot responses
- Coin flip simulation
- Dice roll functionality
- Current date retrieval
- Dynamic chatbot response handling
- Responsive and user-friendly interface
- Custom header and footer components

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3

- bye

## Installation

Clone the repository:

```bash
git clone https://github.com/rkvm9908/TalkMate-Chatbot.git
```

Navigate to the project folder:

```bash
cd talkmate
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build project:

```bash
npm run build
```
